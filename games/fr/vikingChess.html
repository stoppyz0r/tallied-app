Échecs vikings

Renverser les blocs, puis le roi · 2–12 joueurs · Jeux de boules, de lancer et de piste
Aussi appelé Kubb

Qu’est-ce que c’est ?

Un jeu de lancer venu de Scandinavie, avec des blocs de bois et un roi au centre du terrain. Deux équipes lancent des bâtons sur les blocs adverses ; qui les a tous renversés peut viser le roi.

Comment on joue

Mise en place : Le terrain mesure environ 5 × 8 mètres. Cinq blocs de base se dressent sur chaque ligne de fond, le roi au centre. Chaque équipe dispose de six bâtons.

Lancer : L’équipe qui commence lance les bâtons par en dessous, en rotation verticale, depuis sa ligne de fond sur les blocs de base adverses. L’autre équipe lance ensuite les blocs renversés dans la moitié de l’équipe lanceuse, où ils sont redressés comme blocs de terrain.

Blocs de terrain : L’équipe dont c’est le tour doit d’abord renverser tous les blocs de terrain dans la moitié adverse avant que les blocs de base comptent. Si un bloc de terrain reste debout, l’autre équipe peut lancer depuis la ligne de ce bloc à son tour suivant.

Le roi : Une fois que l’équipe a renversé tous les blocs de terrain et de base adverses, elle peut lancer ses bâtons restants sur le roi depuis la ligne de fond. S’il tombe, elle gagne le set. L’équipe qui renverse le roi trop tôt perd aussitôt le set.

Fin : On joue généralement en deux sets gagnants ; en tournoi, les blocs de base encore debout comptent souvent aussi.

Objectif

Renverser d’abord tous les blocs adverses, puis le roi – et gagner ainsi le nombre de sets convenu.

Le décompte en bref

D’abord les blocs du terrain, puis les blocs de base adverses, puis le roi. Si le roi tombe trop tôt, le set est perdu. Généralement deux sets gagnants.

La saisie dans l’app

Jeu de lancer sur gazon pour deux équipes. Après chaque set, vous touchez l’équipe gagnante, avec les blocs de base encore debout si vous le souhaitez – l’app compte les sets jusqu’à la victoire et garde les équipes.
